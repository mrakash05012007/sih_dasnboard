# SIH Dashboard

A Web Dashboard application for Smart India Hackathon (SIH), built using **React** and **Vite**.

---

## 🚀 Features

- **Fast Build & HMR**: Powered by [Vite](https://vitejs.dev/) for quick development and instant hot module replacement.
- **React Framework**: UI built using modern React functional components.
- **Oxlint Setup**: Lightweight, fast JavaScript/JSX linting configured via `.oxlintrc.json`.
- **Environment Configuration**: Pre-configured environment variable templates (`.env`, `.env.example`).

---
